# selora

Open-source command-line client for the Selora AI API gateway (default base URL
`https://api.selora.lol`). The CLI lets you log in, check your balance and usage,
list models, manage API keys, and run quick chats from the terminal.

## Install

```sh
npm i -g selora
```

Or run it without installing:

```sh
npx selora --help
```

## Quickstart

```sh
selora --help
```

Command reference coming soon. Planned commands: `login`, `logout`, `balance`,
`usage`, `models`, `keys`, `chat`.

## Status

Under construction, v0.1.0. The current release is a scaffold: the binary,
version flag, and help output work; functional commands land in upcoming

# Code of conduct

A short one, in plain words.

**Be decent to each other.** This repository's issue tracker, PR reviews, and
any other project channel are shared workspaces. Everyone here — maintainer,
contributor, or first-time reporter of a typo — is entitled to the same
baseline: respect.

**Harassment is not tolerated.** That includes personal attacks, demeaning
comments about anyone or any group, unwelcome sexual attention, publishing
another person's private information, and sustained disruptive behavior.
Arguing hard about a technical decision is fine; arguing about the person
making it is not.

**Keep it technical.** The best contribution to a CLI project is a precise
bug report. Off-topic campaigning, advertising, and vendetta threads will be
removed.

## Enforcement

This project is maintained by a single owner; enforcement is the owner's call.
Consequences range from a warning to a permanent ban from the repository's
channels, scaled to the severity and repetition of the behavior. Reports of
conduct violations can be made privately via GitHub's report mechanism on the
offending content, or by opening a private security-adjacent channel — the
repository's issue tracker is public, so do not use it to report a person.

This conduct statement applies wherever the project's name is being used in
an official capacity (this repository and its release channels). It is
original prose written for this project; it is not a substitute for, or
endorsement of, any larger document set.
